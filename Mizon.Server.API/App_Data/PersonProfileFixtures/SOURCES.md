# Mizon artist profile test collection

The ten people are fictional test identities. Each directory contains a portrait,
a panoramic cover and an original photo-textured GLB bust. Audio is synthesized
at seed time and is excluded from Git. These images were generated with the
built-in ImageGen tool. No third-party photos or recordings are part of this collection.

## ImageGen prompts

- Cover sheet: a photorealistic atlas of ten music header covers in two equal
  columns and five rows, with no borders or text. Cobalt laser stage, a copper
  sunset with an analog microphone, emerald aurora, crimson stage reflection,
  violet piano warehouse, amber drum kit, teal tape studio, indigo rooftop dawn,
  rose velvet and magenta stage fog. Frame each as a dark panoramic editorial
  photograph with room for legible interface controls.
- Portrait sheet: five equal columns and two rows of fictional adult Middle
  Eastern and Persian musicians, ten centered close-up portraits, dark studio
  backgrounds, real skin texture and one light color per cell in the same order
  as the covers. Keep each face safe to crop to a circle, with no text, logos,
  or famous likenesses.

The numbered art files are cropped and compressed outputs of those two sheets.
The GLBs have a closed stylized bust, coat and accents with a matching front texture.
